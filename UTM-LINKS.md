# Trackable links (copy-paste)

Jis jagah link daalte ho, wahan ke hisaab se `utm_source` badlo. Signup hone par admin dashboard
ke "Signup sources" table mein wahi naam dikhega.

| Kahan daalna hai | Link |
|---|---|
| Instagram bio | https://eventcure.in/?utm_source=instagram&utm_medium=bio |
| Instagram post / reel caption (story link sticker) | https://eventcure.in/?utm_source=instagram&utm_medium=story |
| Instagram DM | https://eventcure.in/?utm_source=instagram&utm_medium=dm |
| WhatsApp message | https://eventcure.in/?utm_source=whatsapp&utm_medium=dm |
| Call ke baad bheja gaya link | https://eventcure.in/?utm_source=call&utm_medium=followup |
| Email | https://eventcure.in/?utm_source=email&utm_medium=outreach |
| Kisi specific list/batch ke liye | https://eventcure.in/?utm_source=call&utm_medium=followup&utm_campaign=oct-planners |

Chhota shortcut bhi chalta hai: `https://eventcure.in/?ref=instagram`

## Dhyan rakho
- Sirf **chhote letters, numbers, - _ .** use karo (baaki hata diye jaate hain).
- Bina tag ke link se aaya visitor "direct" gina jaata hai (ya referring site ka naam, jaise google).
- Instagram ka link apne in-app browser mein khulta hai. Agar user wahan se "Open in Chrome" karke signup kare,
  to source kho jaata hai (alag browser). Isliye Instagram pe signup karne wale kuch log "direct" mein dikhenge.
- Source 30 din tak yaad rehta hai, aur **pehla** source hi count hota hai (jab tak naya tagged link na aaye).

## Test kaise karein
1. Private/incognito window mein kholo: https://eventcure.in/?utm_source=test&utm_medium=check
2. Naye test email se signup karo (aur ek baar Google se bhi).
3. Admin dashboard -> "Signup sources" mein `test` dikhna chahiye, aur "Recent signups" mein Source column mein `test · check`.
